Procreate 内置笔尖图库

Procreate 内置笔刷的 Shape 图不会随 .brushset 导出，缺这些图时只能退化成合成圆头。这里提供从 Procreate App 里提取的 292 张内置 Shape，放进笔刷转换器就能补回真笔尖。

原图包（原生分辨率，216.8 MB，分 3 卷）

  • Procreate内置笔尖图库_原图.zip.part1 — 72.3 MB
  • Procreate内置笔尖图库_原图.zip.part2 — 72.3 MB
  • Procreate内置笔尖图库_原图.zip.part3 — 72.3 MB

GitHub 单文件上限 100MB，所以切成 3 卷。三个文件都下完，放到同一个文件夹，双击 合并图库包.bat（或运行下面的命令）合并成一个 zip。

copy /b Procreate内置笔尖图库_原图.zip.part1+Procreate内置笔尖图库_原图.zip.part2+Procreate内置笔尖图库_原图.zip.part3 Procreate内置笔尖图库_原图.zip

合并后大小应为 227349723 字节（216.8 MB），SHA-256：59805819AEAD3CEC1CC4F5494DE01BA52A06AAB22AA1400B0E971EF538516531

精简包（512px 灰度，31.6 MB）

  • Procreate内置笔尖图库_精简512.zip — 31.6 MB

手机、低内存设备推荐这个：笔尖最长边 512（转换器默认就是 512px）。

怎么用

  • Windows 桌面版：把图库 zip 和 exe 放在同一目录（或放进 图库\ 子目录），启动自动加载。
  • 网页版 / 安卓：在选项区点「选择图库 ZIP / 图片」，选这个 zip。
  • 加载成功后选项区会显示「图库包已加载：292 张 …」，之前打的「合成圆头」标签会变成「图库补回」。
